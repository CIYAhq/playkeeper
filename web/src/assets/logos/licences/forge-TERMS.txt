Forge logo, Forge Development LLC, used to identify the server software;
removed on request.

Forge publishes no terms for its logo. Playkeeper shows the file unaltered,
in its server type picker and next to servers that run Forge, only to name
the Forge server software. It implies no endorsement by Forge Development
LLC. The logo remains Forge Development LLC's and is not covered by
Playkeeper's licence. Ask at https://github.com/CIYAhq/playkeeper/issues to
have it removed.
