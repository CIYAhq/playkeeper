**Supported platform (proposed, measured in nested KVM guests only):** Ubuntu 24.04 LTS, x86_64, systemd. Tested guest: 2 vCPU, 3 GB RAM (2971 MB usable), 20 GB disk. The README states 2 vCPUs as the minimum (the tested size; the installer does not check the CPU count). The installer refuses less than 2304 MB RAM (a 2 GB guest was refused), less than 3 GB free disk, other systems (an Ubuntu 22.04 guest; Debian 12 and systemd-less containers) and other CPUs unless `--allow-untested-os` is given. Memory during play with two bots was measured in run 5 (build `f957b08`): the guest used 2196 MB (774 MB available), the server container 1.42 GiB of its 1.5 GiB budget, disk 3.6 GB (`docs/evidence/resources/`). In run 7 the container used 1.29 GiB of 1.5 GiB about a minute after a restart (Overview and `docker stats` agreed).
