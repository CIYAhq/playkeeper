How the templates work

What one holds

The server type and Minecraft version, the rules, the memory, and plugins, mods or a modpack from Modrinth and Hangar. Never a world, the allowlist, operators, ports or passwords. It travels as a link, and everything after playkeeper.io/t# stays in your browser.

How we check each one

We create a server from it on a real Playkeeper, start it and read its log, and list it only if it reaches Done with every plugin enabled. The first checks caught two that would have failed: Iridium Skyblock needs Vault, and Towny can't found a town with its default economy.

Share your own

In your dashboard, a server's menu has Share as a template. It makes a link like these, with that server's software, rules and plugins, and never its world, so a friend can set up the same server on theirs.
