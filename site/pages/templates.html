{{template "h2n" (dict "ID" "holds" "N" 3 "Text" "What a template holds" "Toc" "What it holds")}}
  • It holds the server type and Minecraft version, the rules (difficulty, PvP, hardcore, players), plugins or mods from Modrinth and Hangar, a Modrinth modpack, and data packs by address and checksum.
  • It never holds a world, the allowlist, operators, ports, passwords or console commands.
  • It travels as a link. Everything after playkeeper.io/t# is the template, which your browser reads without sending it anywhere.
{{template "h2n" (dict "ID" "checked" "N" 4 "Text" "How we check each template" "Toc" "How we check them")}}

Before a template is listed, an agent creates a server from it on a real Playkeeper, starts it and reads its log: it has to reach Done with every plugin enabled and no errors. Each page says when, and with which release.

The checks for this batch caught two problems. Iridium Skyblock needs Vault, which its Modrinth page doesn't list, so the skyblock template brings VaultUnlocked. And Towny ships expecting an economy, so its page starts with the setting that lets players found towns.
