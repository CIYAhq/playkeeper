{{template "h2n" (dict "ID" "restricted" "N" 4 "Text" "The five mods other apps can't download" "Toc" "Restricted mods")}}

ATM10 8.2 lists five mods that other apps can't download from CurseForge:

  • Corail Tombstone, Structory, Structory: Towers and I'm Fast. Their authors allow downloads through the CurseForge app only.
  • CC Tweaked Compat. It's gone from CurseForge, though the pack still lists it.

Tools that install from the pack's list stop at these. ATM's server files have all five, so Playkeeper takes them from there, each checked against the SHA-1 CurseForge lists for it.

{{template "h2n" (dict "ID" "manual" "N" 5 "Text" "By hand, with ATM's server files" "Toc" "By hand")}} {{with $m.ServerFiles}}

Download {{.Name}} ({{megabytes .MB}}, {{.Mods}} mods) from the pack's files on CurseForge. It has a start script that installs {{$m.TypeName}} {{$m.Loader}} the first time it runs.

{{end}} 
# Java {{$m.Java}}, then the server files in ./atm10
sudo apt install -y openjdk-{{$m.Java}}-jre-headless unzip
unzip {{$m.ServerFiles.Name}} -d atm10 && cd atm10
echo "eula=true" > eula.txt
ATM10_RESTART=false sh startserver.sh   # installs {{$m.TypeName}}, then starts
  • Memory is in user_jvm_args.txt: raise -Xmx{{gbFlag $m.HeapMB}} for more friends, and leave the machine some for NeoForge.
  • Restarts: the script starts the server again after it stops, unless ATM10_RESTART is false.
  • Java: anything older than {{$m.Java}} stops it with "Minecraft 1.21 requires Java 21". ATM10_JAVA picks another Java.
{{template "h2n" (dict "ID" "settings" "N" 6 "Text" "The settings ATM10 expects" "Toc" "Settings")}}

ATM's start script writes these to server.properties on a new server:

SettingValueWhy
allow-flighttrueJetpacks and flight items would get players kicked for flying.
view-distance8Less land sent to each player.
simulation-distance5Fewer machines and mobs running at once.
max-tick-time180000A long tick doesn't stop the server for 3 minutes.

In Playkeeper, set view distance in the server's Settings and the others in server.properties on the Files tab. Pre-generating the world, on the World tab, also keeps exploring from slowing everyone down.
