{{template "h2n" (dict "ID" "copies" "N" 2 "Text" "Modrinth's copy or CurseForge's" "Toc" "Which copy")}}

Prominence II is on both sites, and the two copies install differently on a server:

  • Modrinth, {{$m.DownloadCount}} downloads. 36 of its mods come inside the pack file itself, and 56 data packs sit in its config folder, where the Paxi mod loads them into every world. Playkeeper's plan for {{$m.Version}} has nothing to add by hand.
  • CurseForge, 12.8M downloads. Six of its mods can only be downloaded by CurseForge's own app. Its server files would have them, but they're a zip inside a zip, which Playkeeper doesn't open, so its plan lists the six for you to add, and 27 data packs it doesn't put on the server.

Give friends the copy the server runs, at the same version, so their mods match it.

{{template "h2n" (dict "ID" "server-mods" "N" 3 "Text" (printf "The %d mods on the server" $m.Mods) "Toc" "Server mods")}}
  • {{$m.PlayerMods}} mods stay off, the ones Modrinth lists as for players' games only. Players get them in their own copy.
  • One of those goes on anyway: Mod Menu, because Forge Config Screens, which the server runs, won't start without it.
  • 36 warnings at start are harmless. Lithium can't read some of BCLib's block classes, logs "Lithium Class Analysis Error" for each, and leaves those blocks as they are.

On a test server on 28 Sep, with Playkeeper's build of that day, the log said Done (48.214s)! once the first world was made.
