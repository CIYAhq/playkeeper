ATM's team ships fixes in bursts: 2.0.3 on 9 Sep, 2.0.4 on 11 Sep, then 2.0.5 and 2.0.6 on 21 Sep. Every player needs the server's version.

On 28 Sep, a server created from its template on the published {{$m.Release}} was online 1 minute 42 seconds after Create, with the {{$m.DownloadSize}} download. Its log said Done (5.906s)!, a timer that starts after the mods have loaded.

{{template "h2n" (dict "ID" "world" "N" 2 "Text" "The world is an island in the void" "Toc" "The skyblock world")}}

To the Sky is All the Mods 10's machines and magic on a skyblock start. The world comes from Skyblock Builder, one of its {{$m.Mods}} mods, through the world type server.properties names: level-type=skyblockbuilder:skyblock. ATM's start script writes that line on a new server.

  • A Playkeeper server gets it too. On the 28 Sep server, server.properties named Skyblock Builder's world type, the pack's seven starting islands loaded, like Simple Life and Witch Cottage, and the area around spawn was ready in 26 ms.
  • Settings says Normal. Playkeeper's world type setting lists only Minecraft's own four, so it shows Normal for this world. The file on the Files tab is what the server uses.
{{template "h2n" (dict "ID" "memory" "N" 3 "Text" "How much memory ATM10 To the Sky needs" "Toc" "How much memory")}}

The pack's CurseForge file asks Java for {{$m.HeapGB}}. NeoForge and {{$m.Mods}} mods take memory outside the heap, so Playkeeper suggests {{$m.Memory}}, of which Java gets {{$m.JavaHeap}}, and the template rounds it up to {{gb (card $m.Template).MemoryMB}}.

  • ATM's server files set no heap. Their user_jvm_args.txt has -Xmx4G commented out, so Java takes a quarter of the machine's memory. In an 11 GB container that was 2.75 GB, and the server still started with nobody on.
  • For 5 or more friends, the sizing guide gives a big modpack {{(sizingFor 8 "modpack").MemoryGB}} GB.

{{template "h2n" (dict "ID" "manual" "N" 5 "Text" "By hand, with ATM's server files" "Toc" "By hand")}} {{with $m.ServerFiles}}

Download {{.Name}} ({{megabytes .MB}}, {{.Mods}} mods) from the pack's files on CurseForge. Its startserver.sh installs {{$m.TypeName}} {{$m.Loader}} the first time it runs.

{{end}} 
# Java {{$m.Java}}, then the server files in ./atm10sky
sudo apt install -y openjdk-{{$m.Java}}-jre-headless unzip
unzip {{$m.ServerFiles.Name}} -d atm10sky && cd atm10sky
echo "eula=true" > eula.txt
sed -i 's/^# -Xmx4G$/-Xmx{{gbFlag $m.HeapMB}}/' user_jvm_args.txt   # the heap the pack asks for
ATM10_RESTART=false sh startserver.sh   # installs {{$m.TypeName}}, then starts
  • Set the heap with sed, not echo >>: the file has no line break at its end, so an added line joins the comment above it and does nothing.
  • It ran on 28 Sep in a Java 21 container: the script installed {{$m.TypeName}}, wrote server.properties, and the server said Done with its {{$m.HeapGB}} heap.
  • Restarts: the script starts the server again 10 seconds after it stops, unless ATM10_RESTART is false. ATM10_JAVA picks another Java, and anything older than {{$m.Java}} stops with "Minecraft 1.21 requires Java 21".
  • Open TCP 25565 in your provider's firewall.
