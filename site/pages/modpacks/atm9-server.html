{{template "h2n" (dict "ID" "server-files" "N" 4 "Text" "What the server files decide" "Toc" "Server files")}}

ATM's server files are the pack as its team runs it: {{$m.ServerFiles.Mods}} mods, all inside a folder called Server-Files-1.1.1. Playkeeper follows them both ways:

  • What they have goes on the server, including mods CurseForge lets only its own app download. Each is checked against the SHA-1 CurseForge lists for it.
  • What they leave out stays off, even when the pack lists it. Mekalus, a shader mod for players' games, stopped ATM9's first start until Playkeeper learned this.
{{template "h2n" (dict "ID" "manual" "N" 5 "Text" "By hand, with ATM's server files" "Toc" "By hand")}} {{with $m.ServerFiles}}

Download {{.Name}} ({{megabytes .MB}}) from the pack's files on CurseForge. Its start script installs {{$m.TypeName}} {{$m.Loader}} the first time it runs.

{{end}} 
# Java {{$m.Java}}, then the server files in ./Server-Files-1.1.1
sudo apt install -y openjdk-{{$m.Java}}-jre-headless unzip
unzip {{$m.ServerFiles.Name}} && cd Server-Files-1.1.1
echo "eula=true" > eula.txt
ATM9_RESTART=false sh startserver.sh   # installs {{$m.TypeName}}, then starts
  • Memory is in user_jvm_args.txt: -Xmx8G is the most Java may take, so the machine needs more than that.
  • Restarts: the script starts the server again 10 seconds after it stops, unless ATM9_RESTART is false.
  • Java: anything older than {{$m.Java}} stops it with "Minecraft 1.20.1 requires Java 17". ATM9_JAVA picks another Java.

On a new server the script also writes allow-flight=true, so flying items don't get players kicked, and max-tick-time=180000, so one long tick doesn't stop the server. Playkeeper leaves these to you: set them in server.properties on the Files tab.
