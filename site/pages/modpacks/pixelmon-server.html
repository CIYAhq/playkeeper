Version {{$m.Version}} is the newest release on {{day $m.Checked}}. The 9.4 versions published since are marked beta.

{{template "h2n" (dict "ID" "jar" "N" 2 "Text" "The 394 MB Pixelmon jar" "Toc" "The big jar")}}

The pack's own file is small. What it downloads isn't: Pixelmon-1.21.1-9.3.16-universal.jar alone is 394 MB, most of the {{$m.DownloadSize}}.

  • Playkeeper 0.4.2 refused it, because it took add-on files up to 256 MiB. From {{$m.Release}} it takes files up to 512 MiB.
  • Every file is checked against the SHA-512 Modrinth publishes before it goes in the mods folder. A half-downloaded jar never reaches the server.
  • The first start takes a while: on the test server, the download and NeoForge's install took under two minutes, and the log said Done (26.349s)! after that.
{{template "h2n" (dict "ID" "server-mods" "N" 3 "Text" (printf "The %d mods on the server" $m.Mods) "Toc" "Server mods")}}

The pack sends every mod to the server as well as to players:

  • Pixelmon itself, with Just Enough Items and JourneyMap.
  • New land to explore: Terralith and Tectonic reshape the terrain, Incendium rebuilds the Nether, and Structory and Structory: Towers add ruins and towers. Lithostitched is the library they share.
  • Four that change players' screens: Essential, FancyMenu, Konkrete and Melody. They load on the server without complaint, and Essential logs one harmless error line at start.

The pack also carries the Pixelmon soundtrack, a 143 MB resource pack. It's for players, so Playkeeper leaves it off the server.
