Version {{$m.Version}}, from {{day $m.Released}}, is the newest. SkyFactory 5 is a skyblock pack: the world starts as empty void, and players build everything from very little.

{{template "h2n" (dict "ID" "files" "N" 2 "Text" "8,502 files, not just mods" "Toc" "8,502 files")}}

Only {{$m.Mods}} of the files the server gets are mods. The rest are configs, default settings and packs of data and resources, 8,502 files in all.

  • Playkeeper 0.4.2 and older refused it, because a pack could put at most 5,000 files on a server. From 0.4.3 the limit is 20,000.
  • It starts on 0.4.4: on 28 Sep, a server made from its template on the published 0.4.4 reached Done (3.621s)! once Forge had loaded its mods.

{{template "h2n" (dict "ID" "manual" "N" 4 "Text" "By hand, with the server files" "Toc" "By hand")}} {{with $m.ServerFiles}}

Download {{.Name}} ({{megabytes .MB}}, {{.Mods}} mods) from the pack's files on CurseForge. Its Install.sh runs the Forge installer it comes with, which writes the run.sh that starts the server.

{{end}} 
# Java {{$m.Java}}, then the server files in ./skyfactory5
sudo apt install -y openjdk-{{$m.Java}}-jre-headless unzip
unzip {{$m.ServerFiles.Name}} -d skyfactory5 && cd skyfactory5
sh Install.sh                  # installs {{$m.TypeName}} {{$m.Loader}}
echo "eula=true" > eula.txt
sh run.sh
  • Memory is in user_jvm_args.txt, which gives Java 4 GB. The pack's README calls 4 GB the minimum, and Playkeeper suggests {{$m.Memory}} for its {{$m.Mods}} mods.
  • The EULA: without eula.txt, the first start stops and writes one set to false.
