Cobbleverse publishes one file, a {{megabytes 239}} .mrpack for players, and its page sends server owners to paid hosts. That file still has everything a server needs:

  • The {{$m.Mods}} mods the server runs. All but one download from Modrinth, {{$m.DownloadSize}} in all; the last comes inside the pack.
  • 1,285 files only players use, the music, resource packs and shaders that make it big. An install tool leaves them off the server.

Two free tools read the pack's list and build the server from it: the itzg Docker image, which Playkeeper runs servers in too, and mrpack-install.

{{template "modpack-docker" (dict "Pack" $m "Slug" "cobbleverse")}}

Open TCP 25565 in your provider's firewall, and give it {{$m.Memory}} or more.

{{template "h2n" (dict "ID" "client-mods" "N" 5 "Text" "The client mods it marks for servers" "Toc" "Client mods")}}

Cobbleverse {{$m.Version}} marks all its mods as needed on the server, including 22 that only change what players see or hear. We read each one's own files:

  • 15 say they're client-only, like Sodium, Iris, Mod Menu, Zoomify and Continuity. Fabric doesn't load them on a server, so they only take disk space.
  • 7 say they run on both sides, like Xaero's Minimap and World Map and FancyMenu, and load on the server as their authors intend.

They don't stop the server. To skip downloading the 15, list them in the itzg image's MODRINTH_EXCLUDE_FILES.

{{template "h2n" (dict "ID" "public" "N" 6 "Text" "Private and public servers" "Toc" "Public servers")}}

From the pack's rules on Modrinth, checked {{day $m.Checked}}:

  • Friends and family: free to host.
  • Public: every mod's licence applies, and some don't allow commercial use.
  • A shop with ranks, perks or paid items rules out Cobbleverse's own structures, trainers and data packs.
  • The name: not "COBBLEVERSE Server", but "COBBLEVERSE Compatible" is fine.
