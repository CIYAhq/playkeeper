The pack also comes in a NeoForge edition. The server and its players need the same edition and version.

{{template "h2n" (dict "ID" "server-mods" "N" 2 "Text" (printf "Only %d of its mods run on the server" $m.Mods) "Toc" "Server mods")}}

The pack marks each mod for players, the server or both, and marks these correctly:

  • {{$m.PlayerMods}} are for players only, like Sodium, Iris, Mod Menu and Entity Model Features, which change what they see. The server leaves them out.
  • {{$m.Mods}} run on the server: Cobblemon itself, Fabric API, Lithium, Krypton and FerriteCore, which make the server lighter, JEI and EMI, Xaero's maps and more.

Cobblemon's own jar is 137 MB, most of the {{$m.DownloadSize}} the server downloads.
