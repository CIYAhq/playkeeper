Needs Playkeeper 0.4.9 or newer.

Good to know

Your own OpenRouter key
It's never shown in chat, the console or the logs.
A spend cap per build and per day
You see it before every build.
One block at a time
Blocks go down one by one, so everyone on the server can watch.
For operators by default
Other players can't start a build unless you let them.
