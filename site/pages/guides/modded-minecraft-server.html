# NeoForge, for a pack on Minecraft 1.21
sudo apt install openjdk-21-jre-headless
java -jar neoforge-<version>-installer.jar --installServer
echo "eula=true" > eula.txt
echo "-Xmx8G" >> user_jvm_args.txt
sudo ufw allow 25565/tcp
./run.sh nogui
# Fabric, for a pack on Minecraft 1.21.1
sudo apt install openjdk-21-jre-headless
java -jar fabric-installer.jar server -mcversion 1.21.1 -downloadMinecraft
echo "eula=true" > eula.txt
sudo ufw allow 25565/tcp
java -Xmx8G -jar fabric-server-launch.jar nogui

Most modded crashes come from three mistakes. The log names the mod.

The versions don't match

requires version 1.21.1 of 'Minecraft', but only the wrong version is present: 1.21.4

{{template "icon" "arrow-right"}}Use the file built for your Minecraft version and loader.

A mod is missing a dependency

Mod 'Create Deco' requires any version of 'Create', which is missing!

{{template "icon" "arrow-right"}}Add the mod it names, in the version it asks for.

A client-only mod on the server

Attempted to load class net/minecraft/client/Minecraft for invalid dist DEDICATED_SERVER

{{template "icon" "arrow-right"}}Minimaps, shaders and menus belong in players' games. Take them off the server.
