Fabric's server page, fabricmc.net/use/server, offers an Executable Server (.jar) for each Minecraft version. It's a small launcher that downloads Minecraft and the Fabric Loader the first time it runs. For Minecraft 26.3, with Fabric Loader 0.19.5 and installer 1.1.2, it's a 182 KB file named after those three versions.

{{template "steps" (dict "Items" (list (dict "Title" "Pick your Minecraft version" "Text" "The page starts on the newest release, with the newest stable loader and installer. Loader 0.19.5 ran our 26.3, 26.1 and 1.21.1 servers alike.") (dict "Title" "Download it into an empty folder" "Text" "Everything the server makes goes in that folder: the world, the mods and the settings.") (dict "Title" "Or fetch it from a terminal" "Text" "The page shows the same curl command as below, for your choice of versions.") ))}} 
# An empty folder for the server
mkdir fabric-server && cd fabric-server
curl -OJ https://meta.fabricmc.net/v2/versions/loader/26.3/0.19.5/1.1.2/server/jar
java -Xmx2G -jar fabric-server-mc.26.3-loader.0.19.5-launcher.1.1.2.jar nogui
# The same with Fabric's installer, in two steps
curl -O https://maven.fabricmc.net/net/fabricmc/fabric-installer/1.1.2/fabric-installer-1.1.2.jar
java -jar fabric-installer-1.1.2.jar server -mcversion 26.3 -downloadMinecraft
java -Xmx2G -jar fabric-server-launch.jar nogui

The installer printed Done, start server by running fabric-server-launch.jar, and left that 616-byte file beside Minecraft's server.jar. Both ways start the same server.

{{template "h2n" (dict "ID" "start" "N" 2 "Text" "Start it, and accept the EULA" "Toc" "First start")}}

Minecraft 26.1 and newer need Java 25, 1.21 needs Java 21, and 1.20.1 Java 17. On Java 21, our 26.3 server stopped at once:

Fabric 26.3 started on Java 21

java.lang.UnsupportedClassVersionError: net/minecraft/bundler/Main has been compiled by a more recent version of the Java Runtime (class file version 69.0), this version of the Java Runtime only recognizes class file versions up to 65.0

{{template "icon" "arrow-right"}}Class file version 69 is Java 25, and 65 is Java 21. Install Java 25 and start it again.

Players connect on port 25565. If they're not on your network, port forwarding covers the router and the firewall.

{{template "h2n" (dict "ID" "mods" "N" 3 "Text" "Add Fabric API and mods" "Toc" "Add mods")}}

The first start makes a mods folder. Download mods marked for Fabric and your exact Minecraft version, from Modrinth or CurseForge, into it, and restart. Fabric's own page says most mods need Fabric API too, and it's one file.

With Fabric API, Lithium and FerriteCore, our server logged Loading 44 mods. Fabric API alone is 38 of them, itself and its 37 modules, and the loader, Minecraft and Java count too. It used about 670 MB with nobody on.

A mod that needs Fabric API, without it

[15:50:34] [main/ERROR]: Incompatible mods found! net.fabricmc.loader.impl.FormattedException: Some of your mods are incompatible with the game or each other! A potential solution has been determined, this may resolve your problem: - Install fabric-api, any version. More details: - Mod 'Chunky' (chunky) 1.5.3 requires any version of fabric-api, which is missing!

{{template "icon" "arrow-right"}}Add Fabric API for your Minecraft version.

A mod made for another Minecraft version

- Mod 'Lithium' (lithium) 0.25.3+mc26.2 requires any version between 26.2 (inclusive) and 26.3- (exclusive) of 'Minecraft' (minecraft), but only the wrong version is present: 26.3!

{{template "icon" "arrow-right"}}Download the file made for your version. Both errors stopped the server before it loaded the world.

A mod for players' games only is no harm: we added Sodium, and the server loaded the same 44 mods and started, without a word about it. Sodium's own file marks it client-only.

{{template "h2n" (dict "ID" "players" "N" 4 "Text" "What players need" "Toc" "Players")}}

It depends on the mods. Our test client, which has no mods at all, tried to join:

Mods on the serverA player with the plain game
Fabric API, Lithium and FerriteCore, on 26.1 and on 1.21.1Joined
The same, and Nature's Compass, which adds an item, on 26.1Turned away: This server requires Fabric Loader and Fabric API installed on your client!

The message went on to name the mod, under The following registry entry namespaces may be related: naturescompass. So players need Fabric Loader, Fabric API and the same version of every mod that adds blocks, items or mobs. Mods that only change the server, like Lithium, they can go without.
