Friends on phones, tablets and Windows choose Play, then Servers › Add Server, with the Bedrock address and port on the server's Join card. That address is your machine's name, not the server's own address, because Bedrock can't follow the record that gives each server its own. Xbox, PlayStation and Switch players need a workaround such as BedrockConnect, which GeyserMC's guide for consoles explains.

  • A server with crossplay stays awake. A Bedrock player can't wake a sleeping server, so sleeping when empty pauses while crossplay is on.
  • Templates don't carry it. Turn crossplay on after you create a server from one.
  • Keep Geyser up to date on the Plugins tab. When Bedrock updates, an older Geyser turns the new version away.
{{template "h2n" (dict "ID" "firewall" "N" 3 "Text" "Open the Bedrock port in your firewall" "Toc" "The firewall")}}

Bedrock connects over UDP, not TCP. Playkeeper publishes the port from the server's container, but a firewall at your provider, or ufw on some images, still has to let it in. Add an inbound rule for UDP 19132 from anywhere, or for the port the Join card shows:

  • DigitalOcean: in the Droplet's Cloud Firewall, if it has one, under Networking › Firewalls.
  • Hostinger: in hPanel's firewall, if it's on, under Security › Firewall.
  • Vultr: in its Firewall group, if you added one, and in ufw on the server, which Vultr's Ubuntu image turns on: sudo ufw allow 19132/udp.
  • Oracle Cloud: in the security list, then in the VM's own iptables as well.
  • A server at home: forward UDP 19132 in your router to the machine.

Java players keep using the TCP game port, 25565 for the first server.

{{template "h2n" (dict "ID" "by-hand" "N" 4 "Text" "By hand, without Playkeeper" "Toc" "By hand")}}
  1. Download Geyser and Floodgate for Spigot, Paper and Purpur from GeyserMC's download page, and put both in the server's plugins folder.
  2. Start the server once, so both plugins write their settings, then stop it.
  3. Set the lines below, and start it again.
  4. Open UDP 19132 on the machine and at your provider.
  5. Add each Bedrock friend from the console with fwhitelist add and their gamertag.
# plugins/Geyser-Spigot/config.yml (Geyser 2.11)
bedrock:
  port: 19132
java:
  auth-type: floodgate
# Otherwise the server refuses Bedrock players' chat
enforce-secure-profile=false

GeyserMC's Geyser setup and Floodgate setup pages cover proxies, Fabric and NeoForge.

{{template "h2n" (dict "ID" "tested" "N" 5 "Text" "What we tested, and what we haven't" "Toc" "What we tested")}}
  • Tested: on a Paper 26.2 server on 28 Sep, a Bedrock test client speaking Bedrock 1.26.51 joined through Geyser and Floodgate with the allowlist on, spawned, chatted and showed up on the Players tab. Turning crossplay off took 12 seconds and closed the port.
  • How that client signed in: offline, so Geyser's check of the Xbox sign-in was turned off by hand for the test. Playkeeper leaves that check on.
  • Not tested yet: a phone, tablet or Windows player signed in to Xbox; a console through BedrockConnect; and a player joining from another network, through a provider's firewall.
