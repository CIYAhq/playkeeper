# Copy downloaded mods to the server over SSH

{{template "h2n" (dict "ID" "friends" "N" 5 "Text" "Give friends the same mods" "Toc" "Friends need the same mods")}}

Players need every mod that adds content, in the same version. The easy way is a pack file they import in the Modrinth App or Prism Launcher.

In Playkeeper, Share with friends on the Mods tab makes that file and a page with each launcher's steps. Server-only mods stay hidden. Playing with friends covers the rest.

{{template "cardshot" (dict "Name" "guide-pack-page" "Alt" "The page friends open: the server's versions, the pack file to download and their launcher's steps." "Sizes" $side)}}
{{template "h2n" (dict "ID" "existing" "N" 6 "Text" "Adding mods to a world you already have" "Toc" "Mods on an existing world")}}
  • New ores and structures appear only in land nobody has visited yet, so explore further out to find them.
  • Removing a mod removes its blocks and items from the world. Back up before you do.
  • Updating Minecraft? Wait until every mod has a version for the new one.
{{template "h2n" (dict "ID" "errors" "N" 7 "Text" "When the server won't start" "Toc" "When it won't start")}}
  • It stops at start-up. The log's last lines name the mod: one for another version or loader, a missing dependency, or a client-only mod. Common modded errors shows each message and its fix.
  • Friends are sent back to the menu. Their mods don't match the server's. Send them the pack file again.
  • It runs out of memory. Mods add up: the sizing guide suggests memory for a few mods or a big pack.

On a Playkeeper server, the Overview explains a crash from the log, with the fix one click away.
