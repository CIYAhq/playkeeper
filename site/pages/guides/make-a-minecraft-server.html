{{template "h2n" (dict "ID" "java" "N" 1 "Text" "Install Java 25" "Toc" "Java")}}

Minecraft 26.1 and newer need Java 25: Mojang's file for 26.3 asks for it by name, and an older Java stops the server at once. Minecraft 1.21 needs Java 21.

  • Ubuntu 24.04: sudo apt install openjdk-25-jre-headless. On 29 Sep the package was 25.0.4.1.
  • Windows and macOS: Temurin 25 from Adoptium, the same Java we ran our server on.
  • To check: java -version should begin openjdk version "25.
{{template "h2n" (dict "ID" "download" "N" 2 "Text" "Download the server jar" "Toc" "Download")}}

minecraft.net's server page links the newest version's jar and gives the command to run it: java -Xmx4G -Xms4G -jar, the file, and nogui. Mojang's version list has the same jar for each version, with its SHA-1. For 26.3 it's 62 MB, so you can download and check it from a terminal:

# An empty folder for the server
mkdir minecraft-server && cd minecraft-server
curl -o server.jar https://piston-data.mojang.com/v1/objects/33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c/server.jar
sha1sum server.jar   # 33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c
java -Xmx2G -jar server.jar nogui
# It stops at the EULA the first time
sed -i 's/eula=false/eula=true/' eula.txt
java -Xmx2G -jar server.jar nogui
# Run it in tmux, so it keeps going when you log out
tmux new -s minecraft
java -Xmx2G -jar server.jar nogui
# Ctrl+B, then D, leaves it running. To come back:
tmux attach -t minecraft
# In the server's console, stop saves the world and quits
stop

{{template "h2n" (dict "ID" "allowlist" "N" 4 "Text" "Let your friends in" "Toc" "Allowlist")}}

Minecraft 26.3's server.properties starts with white-list=true, where 26.2's and 26.1's started with false. So a new server lets in only the players you add, and anyone else sees the game's message:

A player who isn't on the list

You are not white-listed on this server!

{{template "icon" "arrow-right"}}Add them in the server's console, or set white-list=false to let anyone in.

In the consoleWhat it answered
whitelist add NotchAdded Notch to the whitelist
whitelist add and a name with no Minecraft accountThat player does not exist
op NotchMade Notch a server operator, who can use every command

The server looks each name up with Mojang, so spell it as it is in the game. Once our test player's name was on the list, it got in.

PvP isn't in the file any more: in 26.3 it's a game rule, and gamerule pvp answered Game rule pvp is currently set to true.

{{template "h2n" (dict "ID" "port" "N" 6 "Text" "Let players reach it" "Toc" "Port")}}
  • On the same network, players add the computer's local address, like 192.168.1.20. The game shows the server's version and player count when it's reachable: ours showed 26.3, 0 of 20.
  • From anywhere else, open TCP port 25565 in the computer's firewall and forward it on your router: port forwarding, step by step. On a VPS there's no router, just the firewall.
  • A server on your PC runs only while the PC is on. Friends can't play while it's off; a VPS stays on.
{{template "h2n" (dict "ID" "backup" "N" 7 "Text" "Back up the world" "Toc" "Backups")}}

The world is the world folder. Stop the server first, so nothing is written while you copy, then copy it somewhere else, like cp -r world world-backup. What a damaged world does shows how a backup brings one back.

{{template "h2n" (dict "ID" "errors" "N" 8 "Text" "When it won't start" "Toc" "When it won't start")}}
  • Error: LinkageError occurred while loading main class, then UnsupportedClassVersionError and class file version 69.0: 26.3 was started on an older Java, Java 21 in our test. Install Java 25.
  • Error: Unable to access jarfile: Java can't find the file you named. The fix.
  • FAILED TO BIND TO PORT!: something else has port 25565. The fix.

Every error we've tested, with its fix, is on the errors page.
