neoforged.net lists NeoForge's installer files by Minecraft version: pick yours, then Click Here to Download Installer. A NeoForge version shows its Minecraft version: 26.2.0.88 is for Minecraft 26.2, and older ones leave off the 1, so 21.1.252 is for 1.21.1. On 29 Sep, NeoForge for 26.3 was still in beta, so this guide uses 26.2, the newest with a stable build.

# An empty folder for the server
mkdir neoforge-server && cd neoforge-server
curl -O https://maven.neoforged.net/releases/net/neoforged/neoforge/26.2.0.88/neoforge-26.2.0.88-installer.jar
java -jar neoforge-26.2.0.88-installer.jar --installServer
./run.sh nogui
:: In an empty folder, with the installer downloaded into it
java -jar neoforge-26.2.0.88-installer.jar --installServer
run.bat nogui

When NeoForge's Maven is offline, neoforged.net says so and gives the install command with --mirror https://maven.creeperhost.net added.

{{template "h2n" (dict "ID" "installing" "N" 2 "Text" "Install it" "Toc" "Install")}}

The installer is 3.6 MB. On Java 25, ours took 5 seconds and ended with The server installed successfully. It left three files beside the libraries it downloaded, 135 MB of them:

  • run.sh and run.bat start the server: run.sh on Linux and macOS, run.bat on Windows. Each passes Java the arguments in user_jvm_args.txt and in a file NeoForge keeps under libraries.
  • user_jvm_args.txt is where your memory goes. It holds only comments at first, among them: A good default for a modded server is 4GB. Uncomment the next line to set it. The line is -Xmx4G.

Minecraft 26.1 and newer need Java 25, and 1.21 Java 21. The installer isn't needed again, and says You can delete this installer file now if you wish.

Players connect on port 25565: port forwarding covers the router and the firewall.

{{template "h2n" (dict "ID" "mods" "N" 4 "Text" "Add mods, and what went wrong" "Toc" "Add mods")}}

The first start makes a mods folder. Download mods marked for NeoForge and your exact Minecraft version, from Modrinth or CurseForge, into it, with the mods each depends on, and restart. These are the three mistakes we made on purpose:

Waystones, without the two mods it needs

[16:07:45] [main/ERROR] [ne.ne.fm.st.Entrypoint/]: Failed to start FML: net.neoforged.fml.ModLoadingException: Loading errors encountered: - Mod waystones requires balm 26.2.0.7 or above Currently, balm is not installed - Mod waystones requires shogi 26.2.0.5 or above Currently, shogi is not installed

{{template "icon" "arrow-right"}}Add each mod it names, in that version or newer. With Balm and Shogi in, it started.

Balm built for 26.1, on 26.2

[16:09:05] [modloading-worker-0/ERROR] [ne.ne.fm.ja.FMLModContainer/LOADING]: Failed to create mod instance. ModID: balm, class net.blay09.mods.balm.neoforge.internal.NeoForgeBalm java.lang.NoClassDefFoundError: net/neoforged/neoforge/event/level/BlockEvent$BreakEvent

{{template "icon" "arrow-right"}}NeoForge didn't refuse this file: it says it works on 26.1 or newer, as many mods' files do. It crashed a few seconds into the start instead, with Mod loading has failed and a crash report ending in -fml.txt. Use the file made for your version.

Sodium, a mod for players' games, on the server

java.lang.NoClassDefFoundError: org/lwjgl/Version

{{template "icon" "arrow-right"}}LWJGL draws the game on players' screens, and servers don't have it. Take graphics and menu mods off the server. From Playkeeper 0.4.8, the Overview says sodium only runs in players' games, not on servers, and Remove sodium starts the server without it, keeping the file aside. A Fabric server skipped the same mod without a word: how Fabric handles it.

{{template "h2n" (dict "ID" "players" "N" 5 "Text" "What players need" "Toc" "Players")}}

Our test client, which has no mods at all, tried to join NeoForge 26.1.2.112:

Mods on the serverA player with the plain game
FerriteCore, which only lowers the server's memory useJoined
FerriteCore and Nature's Compass, which adds an itemTurned away: You are trying to connect to a server that is running NeoForge, but you are not. Please install NeoForge Version: 26.1.2.112 to connect to this server.

So players need NeoForge in the server's version, and every mod that adds blocks, items or mobs, in the same versions. A pack file for the Modrinth App or Prism Launcher gives them all of it at once.

{{template "install" (dict "ID" true)}}
  1. 1

    Choose NeoForge and a version

    New server offers each Minecraft version's newest stable NeoForge, or its newest beta where there's no stable one yet. It checks the installer against the SHA-512 NeoForge publishes, runs it, and starts the server on the Java it needs.

  2. 2

    Add mods from the Mods tab

    It lists Modrinth's mods for NeoForge and your version, and adds the mods each needs with it. Each file is checked against Modrinth's checksum.

    When a mod fails to start

    Share the mods with friends

    Share with friends makes one link to a page with a file for the Modrinth App or Prism Launcher. Server-only mods stay out of it.
