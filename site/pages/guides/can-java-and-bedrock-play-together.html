Minecraft has two editions, and each only talks to its own kind:

  • Java Edition runs on Windows, macOS and Linux. It has the mods, the plugin servers and most of the big community servers.
  • Bedrock Edition runs on phones, tablets, Xbox, PlayStation, Switch and Windows. It's the one on consoles and in the Microsoft Store.

The two send different data over the network, so a Bedrock game can't join a Java server, and a Java game can't join a Bedrock server. Realms are split the same way: a Java Realm takes Java players only. Buying both for Windows, as Mojang sells them together, gives you two games, not one shared world.

{{template "h2n" (dict "ID" "how" "N" 2 "Text" "How crossplay works: Geyser and Floodgate" "Toc" "How crossplay works")}}

Crossplay happens on a Java server, with two free, open source plugins from GeyserMC:

  • Geyser listens for Bedrock players on a UDP port of its own, 19132 by default, and translates everything between their game and the Java server, both ways.
  • Floodgate lets Bedrock players in with the Xbox account they already sign in with, so they don't need a Java account. It puts a dot in front of their name, like .Steve, so a Bedrock name never clashes with a Java one.

The world stays a Java world. Redstone, farms and mob spawning follow Java's rules for everyone, and Java players join the way they always do.

Consoles only list the featured servers Microsoft picks, with no Add Server button. Workarounds send the console to your server anyway: BedrockConnect changes the console's DNS setting, and GeyserMC's guide for consoles lists the others.

{{template "h2n" (dict "ID" "different" "N" 4 "Text" "What's different for Bedrock players" "Toc" "What's different")}}
  • No Java mods. Bedrock players see what a plugin server has, so crossplay suits Paper and Purpur servers, not modpacks with new blocks and items.
  • Some things Bedrock's game can't show. Chat links can't be clicked, the glowing effect doesn't show, and many plugin commands don't complete with Tab. GeyserMC's list of limitations has the rest.
  • Geyser has to keep up with Bedrock. Bedrock updates itself often, and an older Geyser turns newer Bedrock versions away, so update Geyser when Bedrock updates.
  • Their names start with a dot, so add them to the server's allowlist as . and their Xbox gamertag.

{{template "h2n" (dict "ID" "tested" "N" 6 "Text" "What we tested, and what we haven't" "Toc" "What we tested")}}

On 28 Sep, on a Paper 26.2 server, a Bedrock test client speaking Bedrock 1.26.51 joined through Geyser and Floodgate with the allowlist on, spawned, chatted and showed up on the Players tab. That client signed in offline, so Geyser's check of the Xbox sign-in was turned off by hand for the test.

Not tested yet:

  • a phone, tablet or Windows player signed in to Xbox;
  • a console joining through BedrockConnect;
  • a player joining from another network, through a provider's firewall.
