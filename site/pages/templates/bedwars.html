Screaming BedWars is the most downloaded Bedwars plugin on Modrinth with a build for Minecraft 26. BedWars1058 has more downloads, but stops at 1.21.4.

{{template "h2n" (dict "ID" "map" "N" 2 "Text" "Get a map into its own world" "Toc" "A map first")}}
  • Make a world for arenas in the Console: mv create arenas normal -t flat, then go there with /mv tp arenas.
  • Build the map, or paste one: upload a .schem file to plugins/WorldEdit/schematics on the Files tab, then //schem load it and //paste.
{{template "h2n" (dict "ID" "arena" "N" 3 "Text" "Turn the map into an arena" "Toc" "Set up the arena")}}

The commands, from Screaming BedWars' own help, for an arena called castle:

/bw admin castle add
/bw admin castle pos1            # one corner of the map
/bw admin castle pos2            # the opposite corner
/bw admin castle lobby           # where players wait
/bw admin castle spec            # where spectators go
/bw admin castle team add red RED 2
/bw admin castle team spawn red
/bw admin castle team bed red looking_at
/bw admin castle spawner add iron
/bw admin castle store add
/bw admin castle save

Repeat the three team lines for each team and the spawner line at each resource point. save activates the arena, and players join with /bw join castle.

{{template "h2n" (dict "ID" "rules" "N" 4 "Text" "Game rules it starts with" "Toc" "Game rules")}}

From Screaming BedWars' config on the test server: no crafting in games, no keeping items on death, no friendly fire, and shop villagers can't be killed. Players get a compass to track enemies. Change them in plugins/BedWars/config.yml, and the shop in shop.yml.
