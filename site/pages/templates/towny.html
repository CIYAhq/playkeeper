{{template "h2n" (dict "ID" "economy" "N" 2 "Text" "Change this first: Towny's economy" "Toc" "Change this first")}}

Towny's own config says it: with using_economy on and no economy plugin, "it will not be possible to create towns". Founding a town costs 250, a nation 1,000 and each extra claim 25. Pick one:

  • Free towns, for friends: set using_economy: 'false' in plugins/Towny/settings/config.yml on the Files tab, then restart.
  • Towns that cost money: add an economy plugin and a Vault bridge, then set the prices in the same file.
{{template "h2n" (dict "ID" "first-town" "N" 3 "Text" "Found the first town" "Toc" "The first town")}}
  • /town new Riverside founds a town on the chunk you stand in, with you as mayor.
  • /town claim takes the chunk you're in. Each resident brings the town 8 more chunks to claim.
  • /town add Alex invites a player, and /nation new Northlands starts a nation towns can join.

A town block is one chunk, 16 by 16 blocks from bedrock to sky, and only the town's residents can build in it.

{{template "h2n" (dict "ID" "ranks" "N" 4 "Text" "Ranks and the map" "Toc" "Ranks and the map")}}

Town ranks, like mayor and assistant, come from Towny's own townyperms.yml. LuckPerms is for server-wide ranks, such as moderators: /lp editor opens its web editor.

Playkeeper's live map shows the world, but not town borders yet: no map add-on draws Towny's claims for Minecraft 26.2.
