{{template "h2n" (dict "ID" "meaning" "N" 1 "Text" "Two sides of the same message" "Toc" "What it means")}}

While a player is in the game, the game and the server keep sending each other small messages. When either stops for long enough, the connection ends with Timed out, the text Minecraft 1.21.1's language file gives disconnect.timeout.

On 29 Sep we joined a Paper 1.21.1 server with a test client, then froze the client's process at 14:03:56. The server dropped it 29 seconds later:

The server's log

[14:04:25 INFO]: Frozen lost connection: Timed out [14:04:25 INFO]: Frozen left the game

It's not the error you get joining: a server that can't be reached at all gives connection timed out or Connection refused before you're in.

{{template "h2n" (dict "ID" "which" "N" 2 "Text" "Which side went quiet" "Toc" "Which side")}}
  • One player drops while the others play on: that player's game or connection went quiet, as our frozen client did. A game that freezes, a Wi-Fi drop or a connection that loses packets for half a minute all end this way.
  • Everyone drops at once: the server itself stalled, or its network did. Look in its log for Can't keep up! just before: generating new land put our test server 33 seconds behind, longer than the 29 seconds it gave our quiet client.
  • The server stopped with a watchdog message after a tick that never finished: it froze, and it shuts itself down after a single tick takes a minute, the default max-tick-time of 60000 ms.
{{template "h2n" (dict "ID" "fixes" "N" 3 "Text" "What fixes it" "Toc" "Fixes")}}
  • For one player: check their connection, and that their game has enough memory not to freeze.
  • For the whole server: the fixes for lag. Pre-generate the map, give it a faster CPU and enough memory, and keep less of the world running.
  • For a server that froze: a profiler such as spark, run while it lags, shows what takes the time.
{{template "h2n" (dict "ID" "playkeeper" "N" 4 "Text" "On a Playkeeper server" "Toc" "On Playkeeper")}}

  • How it's running names what slows the server down, like players exploring new land, with the fix.
  • A server that froze gets its own explanation on the Overview, with a button to start it again and a suggestion to run a profiler.
