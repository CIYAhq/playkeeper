On 29 Sep we started Minecraft 1.21.1's server jar in an empty folder. It logged two lines and stopped:

The log

[ServerMain/WARN]: Failed to load eula.txt [ServerMain/INFO]: You need to agree to the EULA in order to run the server. Go to eula.txt for more info.

It also wrote the file it asks about, in the folder it was started from:

eula.txt

#By changing the setting below to TRUE you are indicating your agreement to our EULA (https://aka.ms/MinecraftEULA). #Tue Sep 29 12:15:42 UTC 2026 eula=false

Nothing is broken. Every server needs someone to accept Minecraft's End User License Agreement before it runs.

On Linux, sed -i 's/^eula=false$/eula=true/' eula.txt changes the line in one go.

{{template "h2n" (dict "ID" "gotchas" "N" 3 "Text" "When it still says no" "Toc" "Still says no")}}

We tried the line a few ways on the same server:

The line in eula.txtWhat happened
eula=TRUEStarted
eula = trueStarted
eula=true with a space after itStopped: You need to agree to the EULA
  • A space after true makes the value something other than true. Delete everything after the e.
  • The server reads eula.txt from the folder it starts in, not the jar's folder. Started from somewhere else, it writes and reads another eula.txt there; cd into the server's folder first.
  • On Windows, check the name is eula.txt, not eula.txt.txt: File Explorer hides known extensions unless you turn them on.
