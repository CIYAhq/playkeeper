On 29 Sep we joined two 1.21.1 servers with test clients speaking an older and a newer version:

ServerGame on 1.20.4Game on 1.21.4
Paper 1.21.1Outdated client! Please use 1.21.1Outdated server! I'm still on 1.21.1
Minecraft 1.21.1's own serverIncompatible client! Please use 1.21.1Incompatible client! Please use 1.21.1

The version named is always the server's. Minecraft's own server says Incompatible client either way: in 1.21.1's language file, even its old Outdated messages read "Incompatible client! Please use". Paper still says which side is behind.

{{template "h2n" (dict "ID" "fixes" "N" 2 "Text" "Three fixes" "Toc" "Fixes")}}
  • Play the server's version. In the Minecraft Launcher, the Installations tab adds an installation for any version; pick the one the message names.
  • Update the server to the game's version, once its plugins or mods have builds for it.
  • Let other versions join, on Paper or Purpur. ViaVersion lets newer games join an older server, and ViaBackwards, which needs ViaVersion, lets older ones join a newer server. With both on our Paper 1.21.1 server, the 1.20.4 and the 1.21.4 client each joined the game.

A modded server is different: every player needs the server's modpack, at its version.

{{template "h2n" (dict "ID" "playkeeper" "N" 3 "Text" "On a Playkeeper server" "Toc" "On Playkeeper")}}
  • The Older clients welcome template is a Paper server with ViaVersion and ViaBackwards, 5.12.0 each on its last check, started for real on 0.4.4.
  • The server's public page shows its Minecraft version, so friends can pick it before they join.
  • On a modded server, Share with friends on the Mods tab gives players the exact pack and version.
