If it won't start

  • Error: Unable to access jarfileJava can't open the jar the command names: its real name or folder is different. Each cause, and its fix.
  • UnsupportedClassVersionErrorThe server needs a newer Java. The class file version in the message names it: 61 is Java 17, 65 is Java 21 and 69 is Java 25.
  • Error opening log file 'logs/gc.log'Java 11 and newer won't start while the GC log's folder is missing. Make a logs folder next to the server; the scripts made here do.
  • Unrecognized VM optionYour Java doesn't have that flag: -XX:+UseCompactObjectHeaders needs Java 25, and -XX:+ZGenerational Java 21.
  • Could not reserve enough space for object heapJava can't get that much memory: the heap is bigger than the machine has free, or the Java is 32-bit.
  • It just says KilledThe system ran out of memory and stopped Java. Give the heap less, so Java has room outside it.
