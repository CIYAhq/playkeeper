If it doesn't show

  • It must be 64 × 64 pixelsAny other size is refused: the server logs that it couldn't load the icon, and friends see none.
  • It must be a real PNGA JPEG renamed to .png won't load. The icon made here is always a PNG.
  • Check the name for a second .pngWindows hides file extensions, so server-icon.png can really be server-icon.png.png.
  • On a network, the proxy decidesVelocity and BungeeCord show their own icon, from the proxy's folder.

In Playkeeper, it's in Settings

Open a server's Settings, then Server list, and upload any picture. Playkeeper crops it to 64 × 64 and shows it next to the message friends see. No files, no folders.
