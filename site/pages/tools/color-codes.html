Typing § and where codes work

The section sign isn't on most keyboards, and the game doesn't read it everywhere.

Type the section sign

  • WindowsHold Alt and type 0167 on the number pad, or 21.
  • MacOption + 6 on a US keyboard, or Option + 0, 0, a, 7 with Unicode Hex Input.
  • LinuxCompose, s, o; or Ctrl + Shift + U, then a7 and Enter.
  • PhonesOn an iPhone, hold & on the symbols keyboard. On Gboard it's under ?123, then =\<; on a Samsung, hold S.
  • Or copy it{{template "chip" "§"}}

Where the codes work

  • Java: files, not chatserver.properties (the MOTD), resource packs, language files and world names. Typing § in Java chat disconnects you, so plugins read & instead.
  • Java commands take JSON text/tellraw, /title and signs set by command use JSON, which the /tellraw tab above writes.
  • Bedrock: most textChat, signs, books and quills, anvil names, /title and /scoreboard, but not the newest menus, which show the codes as they are.
  • Hex colours need 1.16 or laterOn Java servers and clients from 1.16, through plugins, MiniMessage or JSON. Bedrock has none.

Where the codes go, in Playkeeper

Add plugins that read & codes from a server's Plugins tab, then edit their messages in the Files tab, right in the browser. For the server list, there's the MOTD generator.
