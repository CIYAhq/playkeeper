Minecraft MOTD generator

The MOTD is the message under your server's name in the server list: two lines, and the list wraps anything wider than about 45 characters. Write yours with colours, see it as friends will, and copy it for server.properties or a MOTD plugin.

If it doesn't look right

  • You see § and letters instead of coloursThe file was saved in another encoding. Use the \u00A7 line this tool writes, which survives any.
  • Line 2 is missingLine 1 is too wide, so the list wraps it and pushes line 2 out. The meters above show when.
  • The old MOTD still showsRestart the server, then press Refresh in the server list.
  • It changes back by itselfSome panels and hosts write the MOTD from their own settings at every start. Change it there, or use a MOTD plugin.
  • On a network, the proxy decidesVelocity and BungeeCord show their own MOTD, from their own config.

In Playkeeper, it's in Settings

A server's Settings has its message and icon under Server list, with a preview like this one. That message is plain text of up to 59 characters; for colours and gradients, add MiniMOTD from the Plugins tab and paste the MiniMOTD block into its main.conf in the Files tab.
