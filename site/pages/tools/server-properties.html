If a setting doesn't stick

  • It went back to the defaultThe server couldn't read the value, like letters where it wants a number, so it wrote the default in its place.
  • A panel or Playkeeper set it backHosts' panels set some keys from their own settings at every start. Change those there.
  • It's from an older versionpvp, allow-nether, enable-command-block and spawn-monsters are game rules since 1.21.9. The server keeps the lines but doesn't read them.
  • The server won't startWith the management API on, TLS needs a keystore. The editor above warns about that, and about RCON without a password.

In Playkeeper, the common ones are in Settings

Difficulty, game mode, view distance, the most players and the server list's message, in plain words. Its Files tab edits server.properties for the rest and marks the lines Settings sets.
