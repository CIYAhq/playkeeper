Players can't connect

  • Connection refused, as io.netty's AnnotatedConnectException: nothing takes connections at that address and port. The same page covers connection timed out.
{{template "h2n" (dict "ID" "where" "N" 2 "Text" "Where the whole message is" "Toc" "Where to look")}}
  • A player's screen shows the errors from joining: "Failed to connect to the server", then the reason.
  • The server's log, logs/latest.log, has everything the server printed since it started. In Playkeeper it's the Console tab.
  • Crash reports go in the server's crash-reports folder, one file for each crash, with the error's stack trace.
{{template "h2n" (dict "ID" "explained" "N" 3 "Text" "What Playkeeper explains by itself" "Toc" "In Playkeeper")}}

When a server stops by itself, Playkeeper reads its log and names the cause on the server's Overview, with a button for the fix where there is one. It knows these:

  • The port is already in use, or the server couldn't open its port.
  • The server ran out of memory, of memory for code, or hit its thread limit.
  • The disk is full.
  • The Minecraft EULA hasn't been accepted.
  • The server needs a different Java.
  • The world is already open somewhere else, its level.dat file is damaged, or part of it may be damaged.
  • The server froze, or was stopped abruptly.
  • A data pack stopped the world from loading.
  • The server isn't allowed to use its own files.
  • A mod needs another mod or a different version of one, clashes with another, or can't load.
