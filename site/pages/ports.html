Open your VPS's ports

Playkeeper needs two: 8443 opens your dashboard, and 25565 lets friends join. If the installer's link won't open, your provider's firewall is blocking them.

Find your provider, follow its steps, then open the link again.

  • AWS
  • Google Cloud
  • Azure
  • Oracle Cloud
  • DigitalOcean
  • Hetzner
  • Vultr
  • Hostinger
  • Linode (Akamai)
  • Another provider

AWS

  1. In the EC2 console, open Instances, pick your VPS, then its Security tab.
  2. Click its security group, then Edit inbound rules.
  3. Add rule: Custom TCP, port 8443, source Anywhere-IPv4.
  4. Add one more for 25565, then Save rules.

On Lightsail, open your instance's Networking tab and add two rules under IPv4 Firewall: Custom, TCP, 8443 and 25565.

Google Cloud

  1. Open VPC network › Firewall, then Create firewall rule.
  2. Set Targets to All instances in the network, and Source IPv4 ranges to 0.0.0.0/0.
  3. Under Protocols and ports, tick TCP, type 8443,25565 and click Create.

Azure

  1. Open your virtual machine, then Networking.
  2. Add an inbound port rule: destination port 8443, protocol TCP, then Add.
  3. Add one more for 25565.

Oracle Cloud

  1. Open your instance, click its subnet, then its security list.
  2. Add Ingress Rules: source CIDR 0.0.0.0/0, protocol TCP, destination port 8443.
  3. Add one more for 25565.
  4. Oracle's Ubuntu has a firewall of its own too. Run this on the VPS: sudo iptables -I INPUT -p tcp -m multiport --dports 8443,25565 -j ACCEPT && sudo netfilter-persistent save

DigitalOcean

A Droplet has no firewall unless you added one, so the ports are open. If you added a Cloud Firewall:

  1. Open Networking › Firewalls and your firewall.
  2. Under Inbound Rules, add Custom, TCP, 8443, from All IPv4 and All IPv6.
  3. Add one more for 25565.

Hetzner

A Hetzner Cloud server has no firewall unless you added one, so the ports are open. If you added one:

  1. Open Firewalls and your firewall.
  2. Under Inbound, add TCP 8443 from Any IPv4 and Any IPv6.
  3. Add one more for 25565.

Vultr

Vultr's Ubuntu turns on its own firewall, and Playkeeper opens the ports in it for you. If you also added a Vultr Firewall:

  1. Open Network › Firewall and your firewall group.
  2. Add TCP 8443 and 25565, from anywhere.

Hostinger

hPanel's firewall is off unless you turned it on, so the ports are open. If you turned it on:

  1. Open your VPS, then Security › Firewall, and Edit your firewall.
  2. Add rule: accept TCP 8443 from any source.
  3. Add one more for 25565.

Linode (Akamai)

A Linode has no firewall unless you added one, so the ports are open. If you added one:

  1. Open Firewalls and your firewall.
  2. Add an inbound rule: TCP, ports 8443, 25565, from all IPv4 and IPv6, action Accept.

Another provider

Look for Firewall, Security group or Network rules in your provider's panel, and allow TCP 8443 and 25565 from anywhere. If there's none, the ports are already open.

Still won't open?

  • Use the whole link the installer printed, with https:// and :8443.
  • On the VPS, sudo playkeeper status says whether Playkeeper is running.
  • {{.Settings.Community.Ask}}: someone has seen it before.

Later, a free name for your VPS uses TCP 443 and 80 too: open them the same way.
